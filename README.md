# TechTrack Equipment Checkout Management System

TechTrack is a C++ desktop application for managing equipment loans in a school or small organization. Staff can manage equipment and borrowers, check equipment out, record returns, and identify overdue items.

## Features

- Add, edit, search, and view equipment
- Add, edit, search, and view borrowers
- Check equipment out to a borrower
- Record returned equipment
- View active, returned, and overdue checkout records
- Store information in a local SQLite database

## Technologies

- C++
- Qt 6.5
- Qt Creator and Qt Designer
- SQLite
- CMake
- Git and GitHub

## How to Run

1. Install Qt Creator with Qt 6.5 and MinGW 64-bit.
2. Clone or download this repository.
3. Open `CMakeLists.txt` in Qt Creator.
4. Select the Qt Desktop kit.
5. Configure and build the project.
6. Run the application from Qt Creator.

The SQLite database is created automatically when the application runs.

## Project Status

The minimum viable product is complete and runs locally as a desktop application.
